# Time Dilation Explained

Manim animations for a special relativity presentation covering time dilation: the train thought experiment, photon clocks, and the Lorentz factor.

## Running

Built with [Manim Community](https://www.manim.community/) v0.17.3.

```sh
pip install manim==0.17.3
manim -pqh 01-slide.py
```

Rendered output lands in `media/videos/`. Pre-rendered scenes are included there.
